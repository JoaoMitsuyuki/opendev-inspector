# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at risk. Use **Security > Report a vulnerability** in the GitHub repository to send a private report to the maintainers. Private vulnerability reporting must be enabled when the repository is created.

Include affected versions, impact, a minimal sanitized reproduction, and a suggested mitigation when possible. Do not include real credentials or unrelated private source code.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| < 0.1   | No        |
